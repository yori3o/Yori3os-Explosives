# Yori3o's Explosives

Исправления столкновений, найденные ошибки и воспроизводимые проверки описаны в [отчёте проверки кода](docs/bug-review.md).

Мод `yo_bombs`: бомбы, гранаты, динамит и их липкие варианты. Один проект собирается для Fabric и NeoForge на Minecraft **1.21.1, 26.1, 26.2 и 26.3**.

Архитектура основана на Everfall: Stonecutter 0.9.8, Loom Back Compat для Fabric и ModDevGradle для NeoForge. Исходные проекты не изменяются; для сборки они больше не нужны.

| Minecraft | Java | Fabric API | NeoForge | YACL Fabric / NeoForge |
| --- | --- | --- | --- | --- |
| 1.21.1 | 21 | 0.116.17+1.21.1 | 21.1.251 | 3.8.2+1.21.1 |
| 26.1 | 25 | 0.155.3+26.1.2 | 26.1.0.19-beta | 3.9.7+26.1 |
| 26.2 | 25 | 0.161.0+26.2 | 26.2.0.88 | 3.9.7+26.2 |
| 26.3 | 25 | 0.161.0+26.3 | 26.3.0.13-beta | 3.9.7+26.3 |

Fabric Loader: 0.19.5. YACL обязателен на клиенте и сервере; Mod Menu необязателен и используется только на Fabric-клиенте. Для ветки NeoForge 26.1 выбрана версия на базовом Minecraft 26.1. Все зависимости задаются в `stonecutter.properties.toml`.

## Сборка

Запускайте Gradle из корня проекта с JDK 25. Gradle подберёт JDK 21 для Minecraft 1.21.1; при необходимости toolchain скачивается автоматически.

```powershell
.\gradlew.bat buildAll
python tools/verify_artifacts.py
```

В `build/libs/1.0.0/` появятся восемь устанавливаемых JAR, восемь JAR с исходниками и, после проверки, `SHA256SUMS.txt`. Файлы с суффиксом `-sources` предназначены для разработки.

Одна комбинация:

```powershell
.\gradlew.bat :1.21.1-fabric:buildAndCollect
.\gradlew.bat :26.3-neoforge:buildAndCollect
```

На Linux/macOS используйте `./gradlew` вместо `.\gradlew.bat`.

## Разработка

```powershell
.\gradlew.bat :26.2-fabric:runClient
.\gradlew.bat :1.21.1-neoforge:runServer
```

Каждая комбинация использует отдельный каталог игры `run/<minecraft>-<loader>/`, чтобы разные версии не открывали один мир. Конфигурация сохраняется в `config/yo_bombs-server.json5` относительно каталога игры. Существующий формат и имена настроек сохранены. Сервер читает собственный файл конфигурации; автоматическая синхронизация настроек с клиентами не добавлялась.

| Каталог | Назначение |
| --- | --- |
| `src/main/java` | Общая логика предметов и снарядов, настройки, содержимое вкладки, добыча |
| `src/main/resources` | Общие текстуры, звуки, локализации, теги и метаданные |
| `src/fabric/java`, `src/neoforge/java` | Инициализация, регистрация и события загрузчика |
| `src/fabric/legacy`, `src/fabric/modern`, `src/neoforge/modern` | Различия API загрузчиков и целевых методов mixin |
| `src/mc/legacy`, `src/mc/modern` | API Minecraft, mixin взрывов, применение предметов, форматы рецептов и моделей |
| `src/mc/loot-legacy`, `src/mc/loot-modern` | Числовые провайдеры добычи до 26.3 и начиная с 26.3 |
| `versions/<minecraft>-<loader>/build` | Сгенерированные исходники и результаты отдельного варианта |

Общий код не импортирует API загрузчиков и не загружает клиентские классы при инициализации сервера. Изменения поведения при переносе: устранены повторная регистрация сущностей и неправильные стандартные предметы снарядов; взрывы выполняются только на сервере; раздатчик запускает таймер; cooldown назначается до расходования последнего предмета; расчёт урона защищён от нулевого радиуса.

`tools/verify_artifacts.py` проверяет матрицу JAR, метаданные и entrypoint-классы, уровни Java, refmap Fabric 1.21.1, рецепты, модели, текстуры, звуки и локализации. Это проверка упаковки; она не заменяет игровую проверку бросков, отскоков, прилипания и взрывов.

Для автоматической серверной проверки:

```powershell
python tools/smoke_servers.py
```

Проверка использует изолированные каталоги `run/smoke/<minecraft>-<loader>/`, запускает серверы по одному и сохраняет результаты в `build/smoke/report.json`. На NeoForge проверяются загрузка мира, создание всех шести снарядов, завершение их таймеров и таблицы добычи. Fabric проверяется до запроса EULA, если в тестовом каталоге нет уже принятого `eula.txt`; скрипт не меняет этот файл. Также можно передать отдельные варианты, например `python tools/smoke_servers.py 1.21.1-neoforge 26.3-neoforge`.
